# Nest Assured block theme

A lightweight Full Site Editing theme built for the Nest Assured protection proposition.

## Design system

- Navy `#102943`
- Warm gold `#c79a54`
- Cream `#f7f1e7`
- Georgia headings and a system sans-serif body stack
- No remote font requests
- Responsive layouts from 390 px mobile to wide desktop
- Reduced-motion support, visible keyboard focus and print-safe content

## Templates

- Static front page
- Standard pages
- Posts and archives
- Custom 404 page
- Shared header and footer template parts
- Accessible cover menu, guide library components and reduced-motion-aware animation

The header and footer use the optimised WebP bird mark in `assets/images`. The 512 px PNG is retained for the WordPress site icon and future platform exports.
